# New Street — India's Digital Civic Operating System

One Platform. Every Citizen. Every Service. Built for Indian civic governance with AI assistance, complaint tracking, real-time public fund transparency, and 100+ unified services.

## Key Features

- **Sahayak Multilingual AI Assistant**: Speak or type in 12+ Indic dialects. AI translates citizen intent, checks scheme eligibility, auto-fills forms, and tracks complaints.
- **Smart Triage & SLAs**: Auto-detects issues (potholes, water leaks, garbage) and routes them with strict 24-48 hr SLAs.
- **Live Geospatial Ward Map**: Real-time Leaflet GIS layers showing active issues, road closures, and live projects.
- **24x7 Emergency SOS**: 1-tap emergency beacon dispatching ambulance/police, and live flood radar feeds.
- **Public Fund Transparency**: Track municipal budget, contractor performance, and geo-tagged invoices on the open ledger.
- **100+ Citizen Services**: Birth & death certificates, property tax SAS calculations, water bill settlements, trade license renewals, and scholarship applications in one unified interface.

## Getting Started

Open `index.html` in your web browser to experience the platform.
