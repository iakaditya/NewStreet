# 🏛️ New Street — India's Digital Civic Operating System

> **One Platform. Every Citizen. Every Service.**  
> A next-generation civic platform engineered for Indian public administration, transparency, and citizen participation.

---

## 🌟 Overview

**New Street** is a unified digital front door for Indian civic governance, inspired by the high-craft design philosophies of Apple, Linear, Stripe, and GovTech Singapore. It seamlessly connects citizens with municipal corporations, ward-level representatives, emergency services, and live public infrastructure updates.

---

## 🚀 Key Features

### 1. 🏙️ Real-Time Municipal Telemetry & City Hub
- Instant switching between major Indian metropolitan corporations (BBMP Bengaluru, BMC Mumbai, MCD Delhi, GHMC Hyderabad, GCC Chennai, KMC Kolkata).
- Real-time resolution metrics, SLA timers, and field-truck dispatch telemetry.

### 2. 🤖 Sahayak AI Assistant
- Conversational civic intelligence supporting natural language queries in English and Indian regional languages.
- Voice-enabled citizen query simulator, ticket classification, and instant welfare scheme recommendations.

### 3. 📊 Real-Time Public Fund Transparency
- Trackable and interactive Chart.js expenditure vs. allocation visualizers.
- Dynamic category expenditure breakdown (Roads & Bridges, Water & Sewage, Sanitation, Street Lighting, Parks & Recreation).
- Searchable Ward-level budget ledger and contractor audit records.

### 4. 🏗️ Public Infrastructure & Development Projects
- Interactive project catalog with high-resolution photographic before/after progress tracking.
- Budget allocation meters, contractor milestones, and estimated completion timelines.

### 5. 📋 Civic Issue Reporting & SLA Tracking
- Smart complaint lodging with GPS tagging, simulated photo upload, and automatic ticket ID generation.
- 4-stage live progression tracker (`Submitted` → `Assigned` → `In Progress` → `Resolved`).

### 6. 🚨 Emergency Response (112 SOS)
- One-touch emergency trigger with live GPS beacon broadcasting.
- Direct speed-dial integration for Police (112), Ambulance (108), Women Helpline (1091), and Disaster Management (1070).
- Live hospital bed and blood bank availability tracker.

### 7. 👥 Democratic Community Hub
- Civic discussion forums, community proposals, upvoting mechanisms, and live local ward polls.

---

## 🛠️ Technology Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+ modular logic engines).
- **Styling**: Modern CSS3 (Custom design system tokens, responsive glassmorphism, fluid typography, dark accents).
- **Data Visualization**: Chart.js (Interactive line, bar, and doughnut charts).
- **Mapping**: Leaflet.js interactive maps with custom SVG ward markers.
- **Storage**: Client-side state engine with `localStorage` persistence.

## 💻 Local Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/iakaditya/NewStreet.git
   cd NewStreet
   ```

2. **Serve locally**:
   Using Python:
   ```bash
   python3 -m http.server 8000
   ```
   Or using Node.js:
   ```bash
   npx serve .
   ```

3. **Open in browser**:
   - **Landing Page**: [http://localhost:8000/](http://localhost:8000/)
   - **Citizen Dashboard**: [http://localhost:8000/dashboard.html](http://localhost:8000/dashboard.html)
   - **Citizen Registration**: [http://localhost:8000/register.html](http://localhost:8000/register.html)
